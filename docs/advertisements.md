# 양옆 광고 설정

PC 화면의 콘텐츠 왼쪽과 오른쪽에 광고 배너를 하나씩 배치할 수 있습니다. 화면 폭이 1,280px 이상일 때 표시하며, 더 좁은 화면과 모바일에서는 광고 영역과 여백을 숨깁니다. 관리자와 설정 화면에는 광고를 표시하지 않습니다.

## 배너 등록

저장소 루트의 `data/advertisements.json`에서 `left`와 `right`를 각각 설정합니다.

```json
{
  "left": {
    "enabled": true,
    "imageUrl": "/ads/left-banner.webp",
    "href": "https://example.com/campaign",
    "advertiser": "광고주 이름",
    "alt": "광고 이미지의 주요 내용"
  },
  "right": {
    "enabled": true,
    "imageUrl": "",
    "href": "",
    "advertiser": "",
    "alt": ""
  }
}
```

| 항목 | 설명 |
| --- | --- |
| `enabled` | `true`이면 표시합니다. `false`이면 해당 광고를 숨깁니다. |
| `imageUrl` | 배너 이미지 주소입니다. 비어 있거나 허용되지 않은 주소면 광고 자리 안내를 표시합니다. |
| `href` | 배너를 누르면 열릴 주소입니다. 비어 있거나 허용되지 않은 주소면 이미지만 표시합니다. |
| `advertiser` | 광고주 이름입니다. 접근성 안내에 사용합니다. |
| `alt` | 이미지를 볼 수 없을 때 읽을 대체 설명입니다. 핵심 광고 내용을 적어 주세요. |

권장 배너 비율은 **160 × 600**입니다. 실제 너비는 화면에 따라 약 120~160px로 조절됩니다. 더 선명한 이미지는 같은 비율의 320 × 1,200px로 준비할 수 있습니다.

직접 넣는 이미지 파일은 `frontend/public/ads/`에 저장하고, 주소에는 `/ads/파일명.webp`처럼 적습니다. S3·CDN을 연결한 뒤에는 해당 이미지의 공개 HTTPS 주소를 `imageUrl`에 넣으면 됩니다. 이 광고 설정은 기업 게재 신청의 이미지 업로드와 별개입니다.

주소는 `/`로 시작하는 같은 사이트의 경로 또는 `http://`·`https://` 주소만 허용합니다. `//`로 시작하는 주소, 역슬래시·공백·제어 문자가 포함된 주소, 사용자명과 비밀번호가 포함된 주소는 사용하지 않습니다. 이미지와 이동 주소 모두 검사하며 광고 링크는 새 창에서 엽니다.

현재 기본값에는 실제 광고가 없으므로 클릭되지 않는 **광고 영역** 안내가 보입니다. 모든 배너에는 `ADVERTISEMENT` 표시가 붙습니다. 관리자 화면의 등록 기능은 아직 제공하지 않으며, 이 파일로 운영합니다.

개발 중에는 설정 파일 변경이 반영됩니다. 배포 환경에서는 변경 후 프런트엔드를 다시 빌드하고 배포해야 합니다.

## 스폰서 타일 (월 30만 원)

이미지 배너와 별개로, 양옆 영역에는 신청으로 채워지는 **스폰서 타일**이 쌓입니다. 총 20자리(한 번에 보이는 자리는 한쪽 5개씩 10개)이며, 빈 자리는 "+ 내 사이트 광고하기" 타일로 표시되어 `/ads/apply` 신청 화면으로 연결됩니다.

- 신청: 사이트 이름, 한 줄 소개, 주소, 담당자 이메일, 카드 색상에 더해 배경 이미지 주소와 파비콘 주소(둘 다 선택, https만)를 입력하면 `PENDING` 상태로 저장됩니다. 파비콘을 비우면 사이트 주소의 도메인으로 Google 파비콘 서비스에서 자동으로 가져옵니다. 이메일은 공개되지 않습니다.
- 카드: 배경 이미지가 있으면 사진 위에 그라데이션과 파비콘·이름·소개를 올리고, 없으면 선택한 색상 그라데이션으로 채웁니다. 메인 레일의 빈 자리 "+ 내 사이트 광고하기" 타일에는 가격을 쓰지 않고, 신청 화면에서 월 30만 원을 안내합니다.
- 자리 수: 총 20자리. 한 번에 보이는 카드는 양쪽 5개씩 10개이고, 11번째부터는 카드 뒷면에 배치되어 일정 시간마다 카드가 뒤집히며 번갈아 노출됩니다.
- 결제: 자동 결제는 없습니다. 운영자가 이메일로 월 30만 원 결제를 안내하고, 입금을 확인한 뒤 관리자 화면 **스폰서 광고** 탭에서 게재 기간(1~12개월)을 정해 승인합니다.
- 게재: 승인 시각부터 기간이 끝날 때까지 노출되며, 종료 버튼으로 바로 내릴 수 있습니다. 승인 순서대로 왼쪽·오른쪽에 번갈아 배치됩니다.
- 이미지 배너(`data/advertisements.json`)에 `imageUrl`이 설정되어 있으면 해당 쪽 타일 위에 먼저 표시됩니다.
