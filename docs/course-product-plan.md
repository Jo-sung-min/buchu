# 부추 부업 강의 기획

부추 클래스는 **퇴근 후 쓸 수 있는 시간, 추가 실습비, 완성할 결과물로 선택하는 부업 전문 강의**입니다. 강의별로 한 번 구매하고 정해진 기간 동안 수강하는 방식으로 시작합니다.

## 참고 서비스와 차별점

[CLASS101 공식 사이트](https://class101.net/ko)는 다양한 학습 분야를 제공하고 구독과 개별 구매 메뉴를 구분합니다. 부추는 강의 탐색 → 상세 소개 → 커리큘럼 → 구매 → 수강이라는 익숙한 흐름을 참고하고, 기존 부업 정보·커뮤니티와 이어지는 학습 경험을 만듭니다. CLASS101의 강의 자료나 브랜드 자산을 복제하지 않습니다. 참고 확인: 2026-10-15.

| 선택 기준 | 부추에서 제공하는 정보 |
| --- | --- |
| 내 일정에 맞는가 | 주당 권장 학습 시간, 전체 수업 수·시간, 난이도 |
| 얼마가 필요한가 | 개별 강의료와 추가 실습비를 구분하고 준비물 공개 |
| 무엇을 만들게 되는가 | 링크 소개 콘텐츠, 디지털 자료, 서비스 소개서 등 구체적인 결과물 |
| 배운 뒤 어디서 시작하는가 | 관련 부업 소개, 모두의 마케터·도와줘! 연결 |
| 구매 전에 확인할 수 있는가 | 커리큘럼, 지정 수업 미리보기, 강사 소개, 수강 기간과 환불 안내 |

추가 실습비와 학습 시간은 강사가 제시하는 계획용 정보입니다. 개인의 실행 속도·도구 선택에 따라 달라질 수 있습니다. 수익이나 취업·판매 성과를 보장하지 않으며, 근거 없는 매출 수치·후기·수강생 수를 표시하지 않습니다.

## 대상과 강의 분야

첫 부업을 탐색하는 사람, 본업과 병행할 수 있는 작은 작업을 찾는 사람, 이미 가진 경험을 콘텐츠나 서비스로 정리하려는 사람을 대상으로 합니다.

| 분야 | 학습에서 다룰 실행 과제 |
| --- | --- |
| 제휴마케팅 | 상품 선정, 광고 표시, 소개 콘텐츠와 링크 배치 |
| 콘텐츠·SNS | 독자 설정, 콘텐츠 기획·작성·발행 |
| 온라인 판매 | 원가·배송·반품 비용 확인, 상품 소개와 판매 준비 |
| 전자책·디지털 상품 | 문제 선정, 목차·샘플 작성, 자료의 사용 권한 확인 |
| 재능·프리랜서 | 제공 범위, 납품물, 견적·일정·수정 조건 설계 |
| AI 활용 부업 | 반복 작업 분리, 초안 작성, 사실·출처·결과물 검토 |

## 화면과 이용 흐름

1. **부업 강의 `/courses`**: 분야·검색어로 찾고, 입문자용·주 3시간 이내·추가 실습비 0원 조건을 적용합니다. 최대 3개 강의를 선택해 시간·비용·난이도·결과물을 비교합니다.
2. **강의 상세 `/courses/{slug}`**: 목표 결과물, 준비물, 강사, 커리큘럼, 수강 조건, 환불 안내를 확인합니다. 공개 지정된 수업만 무료로 미리 볼 수 있습니다.
3. **개별 구매 `/courses/{slug}/checkout`**: 이름·이메일과 구매 동의를 받고 주문을 생성합니다. 주문 번호와 복구 코드를 보관한 다음 연결된 결제 수단으로 결제합니다.
4. **내 강의실 `/classroom`**: 현재 브라우저의 주문을 확인하거나 주문 번호·복구 코드로 복구합니다. 결제 완료와 유효한 수강 기간이 확인되면 수업을 열고 완료 표시를 저장합니다.
5. **다음 실행**: 관련 부업 상세정보를 확인하고, 도와줘!의 홍보·협업 기회를 탐색합니다. 기존 익명 평가는 부업 프로그램 평가이며 강의 구매 후기와 혼합하지 않습니다.

현재는 회원가입 없이 구매하는 구조입니다. 복구 코드는 수강 권한을 가진 비밀 정보이며 서버에는 해시만 보관합니다. 이메일만으로 주문을 찾거나 코드를 재발급하는 기능, 부추 자체 이메일 발송 기능은 포함하지 않습니다.

## 판매와 운영 구조

- 결제 단위는 강의 1개입니다. 구독·장바구니·묶음 상품·쿠폰은 이번 범위에 포함하지 않습니다.
- 가격과 수강 기간은 주문 생성 시 서버의 강의 정보로 확정합니다. 구매자는 요청 값으로 가격을 바꿀 수 없습니다.
- 수강 기간은 결제사에서 확인한 승인 시점부터 계산합니다.
- 관리자는 강의 소개, 강사, 가격, 수강 기간, 실습비, 결과물·준비물, 커리큘럼, 환불 안내와 문의 이메일을 등록합니다.
- 강의 상태는 작성 중 → 오픈 예정 → 판매 중 → 판매 종료로 관리합니다. 판매 종료는 신규 판매를 중단하며, 이미 구매한 사람은 유효한 수강 권한에 따라 계속 접근합니다.
- 관리자 주문 화면은 상태별 조회와 전액 환불을 제공합니다. 부분 환불은 아직 지원하지 않습니다.
- 기업의 부업 홍보 게재 신청과 강의 등록은 별도입니다. 현재 강의 등록 권한은 관리자에게만 있습니다.

## 현재 준비된 6개 강의는 기획 예시

초기 데이터는 아래 여섯 개이며 모두 `COMING_SOON`, `isDemo=true`입니다. 가격·강사·교육 콘텐츠가 확정된 실제 판매 상품이 아닙니다. 예시 강의는 구매할 수 없고, 서버와 DB에서도 판매 중 상태로 바꾸는 것을 막습니다.

| 기획 예시 제목 | 분야 |
| --- | --- |
| 첫 제휴 링크를 만드는 마케터 입문 | 제휴마케팅 |
| 작은 주제로 시작하는 블로그 콘텐츠 | 콘텐츠·SNS |
| 소규모 온라인 판매 준비 노트 | 온라인 판매 |
| 내 경험으로 만드는 첫 디지털 자료 | 전자책·디지털 상품 |
| 재능을 서비스로 만드는 프리랜서 시작 | 재능·프리랜서 |
| 반복 작업을 줄이는 AI 부업 워크플로 | AI 활용 부업 |

일부 미리보기는 기능을 살펴볼 수 있는 짧은 안내 본문입니다. 나머지 수업은 목차 예시이며 완성된 유료 수업으로 취급하지 않습니다. 실강의를 운영하려면 관리자에서 실제 강사·본문 또는 영상·판매 조건을 준비하고 예시 표시를 해제해야 합니다.

## 출시와 다음 단계

먼저 실제 콘텐츠와 이용 조건이 준비된 소수 강의를 검수해 판매합니다. 운영 설정, 결제 연결, 환불과 수강 확인 절차는 [강의 운영 안내](course-operations.md)를 따릅니다. 현재 결제는 기본 비활성화이며 실제 PG 상점과의 결제·환불 연동 검증은 남아 있습니다.

추후 필요에 따라 회원 계정과 이메일 복구, 비공개 영상 전송, 강의 구매 후기, 강사별 정산, 부분 환불을 별도 범위로 설계합니다. 학습 효과를 확인할 때는 실제 강의 탐색·구매·수업 완료와 문의 내용을 기준으로 삼고, 아직 측정하지 않은 성과를 수치로 제시하지 않습니다.
