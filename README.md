# 부추

나에게 맞는 부업을 찾는 정보성 사이트입니다. 첫 번째 카테고리 **모두가 마케터**에서는 쿠팡 파트너스처럼 상품이나 서비스를 소개하고, 전용 링크를 통해 수익 활동에 참여할 수 있는 프로그램을 모아 보여줍니다.

이 저장소는 프론트엔드와 백엔드를 함께 관리하는 모노레포입니다. 같은 상위 폴더의 `fatell` 프로젝트에서 사용하는 Next.js와 Spring Boot 버전에 맞춰 구성했습니다.

## 구성

```text
buchu/
├─ frontend/             # Next.js 웹사이트
├─ backend/              # Spring Boot API
├─ data/
│  └─ programs.json      # 프론트엔드·백엔드가 공유하는 프로그램 정보
├─ scripts/
│  └─ backend.mjs        # 운영체제별 Gradle Wrapper 실행
└─ package.json          # npm workspace 및 공통 실행 명령
```

| 항목 | 버전 / 기본 주소 |
| --- | --- |
| Next.js | 16.2.12 |
| React | 19.1.0 |
| Spring Boot | 3.5.16 |
| Java | 21 |
| Gradle Wrapper | 8.14.3 |
| 프론트엔드 | `http://localhost:3000` |
| 백엔드 | `http://localhost:8081` |

## 시작하기

Node.js 20.9 이상과 JDK 21을 설치합니다. `JAVA_HOME`은 JDK 21 설치 경로를 가리켜야 합니다. Gradle은 별도 설치하지 않아도 됩니다. 최초 백엔드 실행 시 Wrapper가 필요한 Gradle과 의존성을 내려받습니다.

프로젝트 루트에서 프론트엔드 의존성을 설치합니다.

```sh
npm install
```

첫 번째 터미널에서 백엔드를 실행합니다.

```sh
npm run dev:backend
```

두 번째 터미널에서 프론트엔드를 실행합니다.

```sh
npm run dev
```

브라우저에서 [부추 로컬 사이트](http://localhost:3000)를 엽니다. 위 명령은 Windows, macOS, Linux에서 같은 방식으로 사용할 수 있습니다.

## 환경 설정

프론트엔드의 `BACKEND_URL` 기본값은 `http://localhost:8081`입니다. 다른 주소를 사용하려면 `frontend/.env.local`에 설정한 뒤 프론트엔드를 다시 실행합니다.

```dotenv
BACKEND_URL=http://localhost:8081
```

`BACKEND_URL`은 서버에서 사용하는 설정이며 브라우저에 공개되는 환경 변수는 아닙니다. 프론트엔드의 `/api/*` 요청은 이 주소의 백엔드로 연결됩니다.

프로그램 목록은 백엔드에서 읽고, 백엔드에 연결할 수 없을 때는 공유 데이터인 `data/programs.json`을 사용합니다. 따라서 화면 작업은 프론트엔드만 실행해도 진행할 수 있습니다. 이 대체 동작은 프로그램 목록에 적용되며 모든 API의 오프라인 실행을 의미하지 않습니다.

## 제공 기능과 데이터

- **모두가 마케터**: 제휴 마케팅 프로그램을 탐색하고 공식 안내 페이지로 이동합니다.
- 프로그램 정보는 `data/programs.json`에서 관리합니다. 내용을 수정한 뒤 앱을 재시작하거나 다시 빌드해 반영합니다.
- 저장한 항목은 브라우저의 `localStorage`에 보관합니다. 로그인이나 별도 데이터베이스는 사용하지 않으며 다른 기기와 동기화되지 않습니다.
- 사이트의 프로그램 링크는 공식 안내 링크입니다. 운영자의 수익 추적용 제휴 링크를 자동 발급하지 않습니다.

프로그램 소개는 공식 출처를 바탕으로 정리합니다. 수수료, 참여 자격, 정산 조건은 프로그램 운영사 정책에 따라 바뀔 수 있으므로 참여 전 각 공식 페이지의 최신 조건을 확인해야 합니다. 수익을 보장하거나 제휴사 가입을 대행하는 서비스는 아닙니다.

## 개발 명령

모든 명령은 저장소 루트에서 실행합니다.

| 명령 | 용도 |
| --- | --- |
| `npm run dev` | Next.js 개발 서버 |
| `npm run dev:backend` | Spring Boot 개발 서버 |
| `npm run build` | 프론트엔드 배포 빌드 |
| `npm run typecheck` | 프론트엔드 타입 검사 |
| `npm run lint` | 프론트엔드 타입 검사 (`typecheck` 별칭) |
| `npm run test:backend` | 백엔드 테스트 |

프론트엔드와 백엔드는 별도로 배포할 수 있습니다. 배포 환경에서는 프론트엔드 서버가 접근할 수 있는 백엔드 주소로 `BACKEND_URL`을 설정합니다. 두 앱을 빌드할 때 저장소 루트의 `data/programs.json`이 포함되어 있어야 하며, 빌드 과정에서 이 데이터가 각 앱의 결과물에 포함됩니다.
